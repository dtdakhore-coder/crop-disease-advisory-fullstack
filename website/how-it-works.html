How It Works, Step by Step

From a leaf in the field to advice on the screen.

Take a photo

The farmer snaps or uploads a leaf picture in the app.

Clean it up

The image is resized and normalized so the model reads it consistently.

Classify

The trained model studies the leaf and picks the likely disease.

Score it

We get the crop, the disease and a confidence percentage.

Look up advice

The database returns fertilizer, nutrient and care guidance.

Show the result

Everything appears on one simple screen.

System Architecture

Prediction first, advice second. Easy to keep current — advice sits in a database, so experts can update it without retraining the model.

What is wrong?

The classifier looks at the photo and returns the crop, the disease and a confidence score. That answer becomes the search key for the advisory module.

What should be done?

The database takes that crop and disease and returns fertilizer, nutrient and management tips, plus a short description of the disease.

Main Components

The building blocks of the system.

User Interface

Lets the farmer add a photo and read the outcome easily.

Preprocessing

Converts the photo into the format the model expects.

Classifier

Predicts the likeliest disease and gives a confidence value.

Recommendation Database

Holds crop, disease, nutrient and care information in an organized form.

Result Screen

Shows the diagnosis, confidence and advice in clear, simple language.

Future: Soil Model

A soil / nutrient prediction module, added once trustworthy field data is available.

CropCare AI

An ML-Based Smart Agriculture Decision-Support System for crop disease detection and fertilizer advisory. A screening aid — not a substitute for an agronomist.
